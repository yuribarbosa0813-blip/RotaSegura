## Sobre o projeto

O Rota Segura é um sistema desenvolvido em Java para gerenciamento de locação de veículos.

O sistema permite cadastrar clientes e veículos, realizar locações, controlar a disponibilidade dos veículos, realizar devoluções, calcular valores e salvar o histórico das locações.

## Tecnologias

* Java
* Eclipse
* Programação Orientada a Objetos
* Collections
* Arquivo de texto para persistência

## Principais conceitos utilizados

* Encapsulamento
* Herança
* Abstração
* Polimorfismo
* Generics
* Tratamento de exceções
* Persistência de dados

## Como executar

Abrir o projeto no Eclipse e executar a classe:

`ui.Main`

O sistema será iniciado pelo terminal e apresentará as opções do menu.
